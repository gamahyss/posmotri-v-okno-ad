# Посмотри в окно

«Посмотри в окно» — одностраничное веб-приложение для просмотра коротких видео с видами из окон в разных городах. Пользователь может искать ролики по названию города и времени суток, выбирать видео из списка и подгружать дополнительные карточки.

Проект выполнен в рамках второй проектной работы по HTML и CSS. Интерфейс сверстан по предоставленному макету с использованием Flexbox, кастомных элементов формы, стилизованных состояний кнопок и карточек. Сохранены шаблоны для динамической отрисовки контента, прелоадеры, обработка ошибок и JavaScript-логика из стартового проекта.

## Структура проекта

- `index.html` — разметка страницы и шаблоны карточек, прелоадера, ошибки и кнопки «Показать ещё».
- `styles/style.css` — основная вёрстка и оформление интерфейса.
- `styles/preloader.css` — анимация загрузки.
- `styles/error.css` — оформление сообщения об ошибке.
- `fonts/fonts.css` — подключение шрифтов Oswald и Fira Sans Condensed.
- `scripts/script.js` — получение данных и взаимодействие с видео, карточками и поиском.
- `scripts/download_fonts.py` — загрузка оригинальных файлов шрифтов для локального использования.
